# Vehicle Insurance Management System (VIMS)

A modern web application designed to streamline vehicle insurance operations, including policy lifecycle management, claims processing, and user interactions.

---

## 🚀 Project Milestones & Progress
- [x] **Milestone 1**: Database schema design (`prisma/schema.prisma`)
- [x] **Milestone 2**: Responsive landing page, insurance plans showcase, and UI theme system (`frontend/`)
- [ ] **Milestone 3**: User authentication & JWT session management (In Progress)
- [ ] **Milestone 4**: Policy management, vehicle records, and claims processing
- [ ] **Milestone 5**: Interactive client and administrative dashboards

---

## 🛠️ Tech Stack (Current Phase)
- **Frontend**: React 19, Tailwind CSS, Vite
- **Icons & UI**: Lucide Icons
- **Routing**: React Router DOM
- **Database Modeling**: Prisma ORM, PostgreSQL

---

## ⚙️ How to Run Locally

### Prerequisites
Make sure you have installed on your computer:
* [Node.js](https://nodejs.org/) (Version 18 or higher)
* [Git](https://git-scm.com/)

*(Note: No database or backend setup is required to run the current frontend landing page showcase).*

### Step-by-Step Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/binaluv/VehicleInsuranceSystem.git
   cd VehicleInsuranceSystem
   ```

2. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Navigate to **`http://localhost:5173`** in your browser to view the interactive landing page, explore insurance plans, test the light/dark mode switcher, and review public informational pages.
